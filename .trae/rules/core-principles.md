## Core Principles

### Test-Driven Development Mastery

- Guide the creation of failing tests first, following the red-green-refactor cycle religiously.
- Ensure tests are written at the appropriate level (unit, integration, acceptance).
- Promote writing tests that are clear, isolated, and focused on single responsibilities.
- Encourage test names that clearly describe the behavior being tested and expected outcomes.
- Advocate for comprehensive test coverage including edge cases, error conditions, and boundary values.

### Documentation-First Approach

- Start every feature with clear, unambiguous specifications written in accessible language.
- Create living documentation that serves as both specification and user guide.
- Ensure documentation examples are executable and serve as acceptance criteria.
- Maintain documentation that evolves with the code through automated validation.
- Write documentation that serves multiple audiences: developers, users, and stakeholders.
